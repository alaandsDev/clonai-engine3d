# Research / Evidence Pack v1

Camada pura e offline: `ResearchRequest → ResearchPlan → SourceProvider → SourceDocument → Evidence → FactCandidate → GroundedFact / conflicts / ranking → EvidencePack → GROUNDED_ONLY writer → factual preflight → Semantic Engine → reconciliation → Narrative Director / Auto Director → factual-visual matrix`. Fonte é snapshot, evidência é citação localizável, fato é interpretação estruturada, grounding é admissão pela policy. Nenhum desses conceitos significa verdade verificada universalmente.

```powershell
npm run research:plan -- examples/research/ranking-request.json
npm run research:build-pack -- examples/research/ranking-request.json examples/research/ranking-sources.json
npm run research:inspect -- out/engine3d/research/demo-ranking-five-pack.json
npm run research:ground-script -- out/engine3d/phase19/inputs/process-writer-request.json out/engine3d/phase19/packs/process.json
npm run check:research
```

O único SourceProvider implementado é STATIC_SOURCE_PACK. LOCAL_DOCUMENTS/WEB_SEARCH/OFFICIAL_API/CURATED_DATASET são tipos reservados, sem conectores ativos. Nenhum crawler, chave, API paga, modelo ou rede no core/testes. A fixture real Cold Places não recebeu fontes e permanece REAL_PILOT_BLOCKED_NO_SOURCE_PACK; não se lê o roteiro histórico para extrair facts. Conteúdo real deve ser fornecido como SourcePack explícito, com proveniência e hashes. TTS edge existente é usado somente no vídeo demonstrativo opcional, fora dos gates offline.

ResearchPlan é emitido antes de abrir o SourcePack pela CLI/harness. Perguntas e critérios não incluem respostas. Ranking requer métrica, qualifier e critério de presença humana explícitos quando “vive” é material. Permanente, assentamento, equipe temporária e sazonal não são sinônimos. Os estados RESEARCH_INCOMPLETE/RESEARCH_READY são do pacote factual; SCRIPT_GROUNDED/PRODUCTION_ELIGIBLE dependem também de reconciliação e visual. Um fato CORROBORATED pode possuir prova visual NONE.

SourceDocument conserva raw content, SHA-256, metadata, datas do manifest, locator e licença/proveniência. Nada é buscado pelo locator ou executado. Aceita text/plain, text/tab-separated-values e HTML limitado; rejeita NUL, MIME inesperado, source acima de64KiB por default, total acima de512KiB, normalização acima de64Ki caracteres. Até32 sources/256 evidências são limites máximos configuráveis do request; defaults16/128. Datas não vêm de relógio no core.

HTML é tokenizado sem execução; scripts/styles/nav/aside/iframes são excluídos do texto de extração, mantendo raw snapshot. Títulos/headings/parágrafos/linhas/células são preservados no texto normalizado. Mapping por code unit mantém offsets UTF-16 para sourceSpan original, inclusive entidades HTML e tabelas. Não é um parser HTML universal; markup malformado pode exigir intake preparado. Evidência de tabela guarda row/column, headerContext e headerSpan. Citação exata de HTML pode conter markup entre células; normalizedText fornece a leitura extraída.

Extractor literal pt-BR v1 suporta temperaturas com verbo registrou/apresentou/relatou, qualifier explícito, valor/unidade e contexto temporal; residência/presença em construções limitadas; tabelas de processo e tabelas `Local/Métrica/Valor/Unidade/Contexto/Presença`. Outras enumerações de EvidenceType são contratos reservados, sem inferência automática fictícia. Inglês é LANGUAGE_UNSUPPORTED_FOR_EXTRACTION. Datas/decimais/sinal, aproximação, relato e presença temporária são preservados. Extração HIGH significa correspondência clara ao texto, não truth probability. Linha instrucional na fonte não altera policy e não é usada como fato.

Quality usa authority/directness/specificity/recencyRelevance/methodTransparency/independence/extractability, com razões explícitas, não probabilidade de verdade. Authority3 para primary,2 para academic/institutional,1 reference/news,0 other; directness até2 por declaração, specificity até2, outros até1. HIGH≥9, MEDIUM≥6, demais LOW; idioma não suportado/sem texto é REJECT. Freshness não é deduzida de clock ou por ser URL recente. Metadata é fornecida, não autenticada por este módulo. LOW isolada não admite PRIMARY.

Corroboration agrupa sources por hash raw/normalizado, publisher normalizado, locator e origin/sharedOrigin declarado. Cópias/URLs novas não geram origens independentes automaticamente. É corroboration estrutural dentro do snapshot, sem verificação forense da independência real. Policy minIndependentSources(default1) e minPrimaryQuality(defaultMEDIUM) controlam admissão; dois publishers fictícios de teste exercitam duas origens declaradas, não pesquisa real. CONFLICTED/INSUFFICIENT não podem ser PRIMARY. EvidenceReviewDecision APPROVE/REJECT/NEEDS_REVIEW é contrato e fila diagnóstica; não se exige aprovação humana por evidência nos testes e não há autoaprovação resolvendo conflito.

Conflitos numéricos exigem mesma entidade, predicado, métrica, qualifiers, unidade normalizada e contexto temporal, com valores divergentes. Minimum/average não conflitam diretamente; também não podem ser misturados em ranking de minimum. Temporal diferente é preservado. Quantities mantêm originalValue/originalUnit, normalizedValue/unit, precisão reportada e approximation. °F→°C só se policy permitir; o writer conserva a unidade/precisão originais. O parser de vídeo pode continuar sem suporte para uma realização em Fahrenheit: grounding não fabrica suporte visual.

Ranking é apenas do universo fornecido. Exige fatos admitidos, métrica/qualifier/período/unidades comparáveis e residência pedida. Quatro de cinco gera RANKING_INCOMPLETE, sem quinto inventado. Sem contexto explícito para múltiplos períodos não escolhe o melhor ID. Aproximações exigiriam uma policy de incerteza que não existe aqui, portanto são recusadas no ranking. Ties usam competition rank(1,1,3) e incluem todos no cutoff; ordem alfabética entre empatados é apenas apresentação. Derivação aponta para fact IDs de medição/residência. A realização não pode inverter os ranks derivados; permutações dentro do mesmo tie são permitidas.

EvidencePack tem fingerprints canônicos por conjuntos ordenados de source/evidence/facts. validateEvidencePack reprocessa snapshots, além de conferir hashes/spans/IDs; re-assinar um fato adulterado sem suporte não basta. Source/evidence/fact/qualifier mutations, deletions e fingerprints stale falham. O writer recebe pack validado read-only e não promove facts, modifica sources ou resolve conflitos. SOURCE_ONLY legado continua para fonte direta; o novo caminho exige explicitamente GROUNDED_ONLY e EvidencePack separado, rejeitando sourceMaterial lateral.

Grounded writer realiza tuplas em paráfrases curtas, conserva qualifiers/uncertainty/contexto e usa o parser/diretor existentes para todos os claims/recursos. Não injeta SemanticClaims. Antes do parser, factualPreflight verifica linguagem de realização fechada, spans, fatos essenciais e ordem do ranking. Depois, reconcileGrounding liga claims efetivamente extraídos aos facts/evidence/source. Candidato não pode aumentar executability apagando essentialFactIds/essentialResearchQuestionIds. Scores só competem após hard gates factuais: grounding30, qualifiers15, clarity15, execution15, proof10, continuity5, low ambiguity3, low gaps3, naturalness2, repetition2. Naturalness segue fraca e não foi reescrita como Writer v2.

Matriz visual adiciona um guard de valor/identidade ao display numérico legado: quantidade finita de outro item não vira DIRECT para o fato atual. CompiledNarrative.productionReady é propriedade visual do compilador antigo; somente o envelope grounded e a finalização podem autorizar master factual. finalizeGroundedWriter exige timing medido completo e novo preflight; produção real nunca é autorizada por pack fixture. Vídeo de demo leva DEMO_FIXTURE/NOT_REAL_WORLD_FACTS em metadata/manifest, sem ser apresentado como pesquisa factual do mundo real.

Limites: linguagem/source formats fechados, normalização HTML limitada, qualidade/independência dependentes de metadata, nenhuma busca/entailment universal/tradução, conflitos sem resolução automática e recursos visuais inalterados. Em nenhum ponto o conhecimento do modelo é Evidence. A versão entrega rastreabilidade e recusa honesta, não autonomia de pesquisa aberta ou publicação.
